LKPD 5 : Inter-Subnet Routing (Menghubungkan Dua Network Berbeda)

Siswa Praktikan

Identitas Peserta Didik

Tujuan Pembelajaran

  • Mengonfigurasi IP interface Router untuk menghubungkan dua subnet berlainan.
  • Mengonfigurasi Default Gateway pada PC agar data dapat terkirim lintas subnet.
  • Menganalisis alur pengiriman paket (routing) dan melacak jalur pengiriman dengan perintah `tracert`.

Perangkat & Tools

  • Browser Web (PC/Laptop/Tablet).
  • Simulator PackeTTrino (Embedded).
  • Komponen Simulator: 2 PC, 2 Switch, 1 Router, Kabel UTP Straight, CLI (Ping & Tracert).

Simulator Live PackeTTrino

Interactive Workspace

Gunakan simulator di bawah ini untuk membuat topologi Inter-Subnet Routing: Hubungkan PC-1 ke Switch-1, Switch-1 ke Router Interface eth0. Hubungkan Router Interface eth1 ke Switch-2, dan Switch-2 ke PC-2. Atur Subnet A (192.168.10.0/24) dan Subnet B (192.168.20.0/24).
