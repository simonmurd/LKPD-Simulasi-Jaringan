LKPD 8 : Pelacakan Rute Paket (Traceroute) & Troubleshooting Jaringan

Siswa Praktikan

Identitas Peserta Didik

Tujuan Pembelajaran

  • Menganalisis alur lompatan paket (hop) melintasi router menggunakan perintah traceroute.
  • Mendiagnosis titik kegagalan koneksi (Request Timed Out) pada topologi multi-router.
  • Memahami peranan Time to Live (TTL) dan pesan ICMP dalam mengisolasi gangguan jaringan.

Perangkat & Tools

  • Browser Web (PC/Laptop/Tablet).
  • Simulator PackeTTrino (Embedded).
  • Komponen Simulator: Multi-Router, PC Client, Switch, CLI Interface.

Simulator Live PackeTTrino

Interactive Workspace

Gunakan simulator untuk membuat topologi Multi-Router (misal: PC-Client -> Switch -> Router-1 -> Router-2 -> Router-3 -> Server Target). Konfigurasikan IP Address dan Static/Dynamic Routing. Jalankan perintah `tracert` / `traceroute` dari CLI PC Client menuju IP Server. Simulasikan pemutusan rute untuk mendiagnosis titik kegagalan (*Request Timed Out*).
