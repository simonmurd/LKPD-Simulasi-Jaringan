LKPD 7 : Simulasi Layanan Web Server dan Resolusi Nama Domain (DNS)

Siswa Praktikan

Identitas Peserta Didik

Tujuan Pembelajaran

  • Mengonfigurasi Web Server (HTTP) dan DNS Server pada jaringan lokal.
  • Mengatur pemetaan A Record (Domain ke IP) dan membuat berkas web index.html.
  • Menganalisis proses resolusi nama domain serta pengaksesan web via Web Browser.

Perangkat & Tools

  • Browser Web (PC/Laptop/Tablet).
  • Simulator PackeTTrino (Embedded).
  • Komponen Simulator: 2 PC, 1 Switch, 1 Web Server, 1 DNS Server, Kabel UTP Straight.

Simulator Live PackeTTrino

Interactive Workspace

Gunakan simulator untuk membuat topologi Web Server & DNS: Hubungkan PC-1, PC-2, Web Server, dan DNS Server ke Switch menggunakan Kabel Straight. Konfigurasikan IP Statis DNS Server (192.168.1.10) dan Web Server (192.168.1.100). Tambahkan Record DNS `www.sekolah.sch.id` mengarah ke `192.168.1.100`. Aktifkan HTTP pada Web Server dan lakukan pengujian akses web dari browser PC Client.
