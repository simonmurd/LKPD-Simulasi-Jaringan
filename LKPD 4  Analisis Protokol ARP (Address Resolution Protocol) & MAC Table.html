LKPD 4 : Analisis Protokol ARP (Address Resolution Protocol) & MAC Table

Siswa Praktikan

Identitas Peserta Didik

Tujuan Pembelajaran

  • Mengamati pemetaan IP Address (Layer 3) ke MAC Address (Layer 2) secara visual saat koneksi pertama kali dilakukan.
  • Menganalisis proses pembentukan paket ARP Request (Broadcast) dan ARP Reply (Unicast).
  • Memeriksa isi ARP Table pada PC (`arp -a`) dan MAC Address Table pada Switch.

Perangkat & Tools

  • Browser Web (PC/Laptop/Tablet).
  • Simulator PackeTTrino (Embedded).
  • Komponen Simulator: 3 PC, 1 Switch, Cable Tool, CLI (Perintah ARP & Ping).

Simulator Live PackeTTrino

Interactive Workspace

Gunakan simulator di bawah ini untuk menghubungkan 3 PC ke 1 Switch. Berikan IP 192.168.1.10 (PC-1), 192.168.1.20 (PC-2), dan 192.168.1.30 (PC-3). Amati proses ARP sebelum dan sesudah koneksi pertama dibuat.
