LKPD 3 : Konfigurasi IP Addressing Class C & Uji Konektivitas (PING)

Siswa Praktikan

Identitas Peserta Didik

Tujuan Pembelajaran

  • Mengonfigurasi IP Address Kelas C dan Subnet Mask pada perangkat PC dalam satu segmen.
  • Menguji konektivitas antar komputer menggunakan perintah CLI (`ping`).
  • Menganalisis pesan balasan ICMP (Echo Request/Reply) seperti *Reply*, *Request Time Out*, dan *Destination Host Unreachable*.

Perangkat & Tools

  • Browser Web (PC/Laptop/Tablet).
  • Simulator PackeTTrino (Embedded).
  • Komponen Simulator: 3 PC, 1 Switch, Cable Tool, CLI (Ping Tool).

Simulator Live PackeTTrino

Interactive Workspace

Gunakan simulator di bawah ini untuk membuat topologi Star menggunakan 3 PC yang terhubung ke 1 Switch. Atur IP Address Class C pada tiap PC, lalu lakukan pengujian konektivitas menggunakan perintah `ping` pada CLI.
