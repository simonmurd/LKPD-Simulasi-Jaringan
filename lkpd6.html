LKPD 6 : Simulasi Layanan DHCP Server untuk Alokasi IP Otomatis

Siswa Praktikan

Identitas Peserta Didik

Tujuan Pembelajaran

  • Mengonfigurasi DHCP Server untuk membagikan parameter jaringan secara otomatis.
  • Mengatur IP Pool, Subnet Mask, dan Default Gateway pada layanan DHCP Server.
  • Menganalisis proses alokasi IP dinamis (DORA) dan verifikasi konektivitas antar-klien DHCP.

Perangkat & Tools

  • Browser Web (PC/Laptop/Tablet).
  • Simulator PackeTTrino (Embedded).
  • Komponen Simulator: 3 PC, 1 Switch, 1 DHCP Server, Kabel UTP Straight, CLI/IP Config.

Simulator Live PackeTTrino

Interactive Workspace

Gunakan simulator di bawah ini untuk membuat topologi DHCP Server: Hubungkan 3 PC dan 1 DHCP Server ke Switch 24-Port menggunakan Kabel Straight. Konfigurasikan IP Statis Server (192.168.1.1/24) dan aktifkan layanan DHCP Pool (192.168.1.10 - 192.168.1.50). Ubah mode alokasi IP pada PC-1, PC-2, dan PC-3 menjadi DHCP Client.
